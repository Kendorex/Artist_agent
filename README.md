# Лабораторная работа: АХ: Агент-художник

## Задание

Реализовать многоагентную систему для рисования концептуальных картин на заданную тему. Использовать примитивы общения с Responses API в Image Generation API в Yandex Cloud. 

В итоге нужно представить коллекцию из 3-5 картин и соответствующие им диалоги агентов. В качестве вдохновения используйте работу [Многоагентное рисование](https://soshnikov.com/art/vibedraw/ru). 

## Отчёт

Код работы помещается в файл Agent_Artist.ipynb, с пояснительными комментариями по принципам реализации. Отчёт по работе оформляется в [REPORT.md](REPORT.md) на основе заданного там шаблона.

## Оценивание

Работа оценивается по баллам в 10-балльной системе:

* Минимальная реализация - рисование 3-5 картин на основе диалога двух и более LLM между собой [2 балла]
* Наличие агентского контура обратной связи с VLM [+2 балла]
* Реализация сайта с результатами на GitHub Pages / SourceCraft Pages через Coding-агента [+1 балл]
* Оригинальность работы, крутизна финального материала, необычность и самобытность - [+0-3 балла]
* Использование OpenWeight-модели с HuggingFace для генерации изображений (Stable Diffusion, etc.) помимо Yandex ART [+2 балла]

Важнейшими элементами оценки являются:

* **Мотивирующий абзац** (*Project Statement*) - кратко описывает, чем ваша работа оригинальна, отличается от простейшей реализации, почему преподавателю стоит на неё внимательно и с интересом посмотреть.
* **Выводы** - чему вы научились, какие уроки для себя извлекли.
